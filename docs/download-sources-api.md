# 下载来源与查询接口

这些是桌面本机所有者的只读查询接口，不向独立外部 API 的 bearer token 开放。校验回环连接、Host、Origin，拒绝 Authorization；接口响应不可被 HTTP 缓存。

## GET /api/download/sources

返回 `{sources:[...]}`，每项包括 `id`、`name`、固定 `url` 和可选 `note`。无配置、启用或版本字段。返回清单本身不请求外站。

| id | name | 固定根地址 |
| --- | --- | --- |
| bangumi | Bangumi.moe | `https://bangumi.moe/` |
| acgrip | ACG.RIP | `https://acg.rip/` |
| dmhy | 动漫花园 | `https://share.dmhy.org/` |
| nyaa | Nyaa | `https://nyaa.si/` |

只包含这四个适配器；清单不是实时可用性或使用许可承诺。

## GET /api/download/resources

参数：四个来源之一的 `source`、最长 200 字符的 `keyword`、可选 `cursor` 和 `refresh=1`（或 `0`）。不接受 `revision`、站点地址或其他额外参数。无权限返回 403，无效参数／游标返回 400。

保留 `source/resources/nextCursor/status/cached` 列表契约。status.kind 为：

- `success`：已识别的结果或有证据的真实空列表。
- `restricted`：验证／访问限制。
- `rate_limited`：含 retryAt，重试遵守站点冷却。
- `error`：超时、连接、解析、目标安全或代理不支持错误。

来源／关键词／内置地址不匹配的游标返回 400。成功结果默认在服务端内存缓存 30 秒；刷新绕过结果缓存，但不绕过站点冷却。各站独立处理失败，取消后的迟到响应不能写入缓存或当前页面。

Nyaa 的实际 HTTP 请求在同一后端进程内至少间隔 5 秒，跨服务实例共用等待队列；刷新、翻页、关键词切换、RSS 回退和每次允许的重定向均受约束。命中缓存不占请求时隙。等待期间可以取消或超时，取消后不发送请求，也不额外占用下一个时隙；其他来源不受该间隔影响。原有请求总超时及 429／Retry-After 冷却仍有效，不因间隔等待而延长超时。间隔状态不写数据库，重启进程后不保留，也不跨设备共享。

进入下载页即加载当前会话已提交的查询，首次默认选择四源、空关键词最新列表；心愿单链接会自动提交带入的关键词。勾选变更后通过搜索生效。旧会话中不支持的来源 ID 被过滤；没有任何可恢复来源时回到四源默认值。应用启动本身不启动下载列表查询。

路径／参数由适配器生成，详情与翻页链接必须同站；网络层还校验固定来源、DNS、重定向、TLS 和实际连接目标。检测到无法安全支持的代理会明确失败，不静默直连。无 Cookie、账号密码、自定义请求头、脚本执行或验证码绕过能力。

## 旧配置兼容

`GET/PUT /api/settings/download-sources` 已撤下，均返回 404。旧 `download_sources*` 记录不删除，但不再读取执行，并从通用设置响应和通用导出排除。通用 `PUT /api/settings` 拒绝写入这些字段，整次混合保存失败，不顺带修改其他设置。完整数据库备份仍可能包含历史配置，应妥善保护。
