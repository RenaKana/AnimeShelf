# 桌面候选隐私与数据流

此说明对应本候选的实际代码，不是完整安全审计或服务提供方隐私政策。

## 本机保存

应用在用户本机保存媒体库目录、文件记录、分类、合集、心愿单、显示偏好、API 凭据及备份。便携版默认使用 EXE 旁 `data/`，可用 `ANIMESHELF_DATA_DIR` 改位置。完整数据库备份可能包括历史秘密和下载来源，需像原数据库一样保护；通用设置接口会隐藏秘密字段。

Electron 浏览器会话／缓存默认使用 Windows 用户配置目录，未统一迁移进 `data/`；服务登记默认在 `%LOCALAPPDATA%/AnimeShelf/run/`（可用 `ANIMESHELF_RUNTIME_DIR` 指定）。便携版是免安装程序，不表示所有痕迹都只写在 EXE 旁。登记材料包括进程和本机控制信息，应保持本机权限，不随排错材料公开。

候选源码及便携包不带真实设置、密钥、媒体库、海报缓存或备份。没有手机应用、找番或 AI 服务；旧记录保留但没有相应可执行入口。

## 对外请求

| 功能 | 目的地 | 发送范围／触发 |
| --- | --- | --- |
| 普通元数据 | AniList GraphQL、Bangumi API、TMDB API | 搜索词（可能源于整理后的文件夹／作品名）、条目 ID、语言／查询参数及应用标识；AniList 匿名调用，Bangumi 可附该服务的用户令牌，TMDB 附该服务的用户密钥。手动操作或用户启用的后台匹配／刷新触发；搜索词本身仍可能包含本地命名信息。 |
| 追番信息 | AniList、Bangumi API；随包 bangumi-data 数据 | 查询作品／放送信息；AniList 批次可包含 AniList ID 与 MAL ID。收藏读取、服务启动和周期刷新可触发请求。本地 bangumi-data 读取本身不需要联网，数据内的 AniDB／MAL 等外链不是这些站点的自动 API 接入。 |
| 海报 | 元数据返回的图片主机 | 请求图片 URL；远端会看到连接 IP、请求头和时间。图片不附加其他服务密钥。 |
| 下载列表 | 内置的 Bangumi.moe、ACG.RIP、动漫花园、Nyaa HTTPS 站点 | 进入下载页即查询已选来源，首次默认四源；搜索／刷新／分页及心愿单资源搜索也会触发。发送关键词（可能由心愿单作品名带入）、固定分类、页码／列表路径及固定应用标识。无关键词时请求最新列表。不附媒体库路径、文件内容或其他服务密钥。 |
| 下载详情 | 用户主动打开的已校验站点链接 | 系统浏览器按其自身 Cookie／隐私设置访问；应用不会代填账号、Cookie 或自定义请求头。 |
| Everything | 用户配置的 Everything HTTP 服务 | 媒体库目录／查询条件；这是扫描所用的另一个本机或用户配置服务，不是随包程序。 |
| 外部 API | 本机独立监听端口 | 经用户创建的令牌及角色授权返回库记录，包括已保存的供应商来源 ID、简介、评分／分类等元数据；收藏可包含本地图片路径字符串，不是图片字节。部分角色可修改文件。默认停用。 |

下载站点地址固定在程序中，不再提供自填地址或来源启停设置。页面会恢复当前会话已提交的关键词和来源选择，自动请求保留的来源；不支持的旧来源 ID 会被过滤。仅启动应用、不进入下载页不会触发下载列表查询。切换查询或离开页面会取消对应请求，迟到结果不能覆盖当前查询；缓存与游标绑定内置站点、来源和关键词，不影响其他媒体库任务。

旧 `download_sources*` 设置保留在本机数据库，但不再读取执行，也不进入通用设置响应。原专用读取／保存接口返回 404；通用设置接口拒绝写入这些字段。下载查询仍仅限本机所有者。用户自主导出的完整备份仍可能包含旧配置，应按私人数据保护。

下载网络请求校验 DNS 的全部解析结果，固定到通过检查的公网 IP，并核对 TLS 证书及实际连接对端；每次重定向重新验证。不安全或不支持的代理明确失败，不退回直连。请求不绕过验证页，不转发 Cookie，保留大小、超时、并发和限流边界。

Nyaa 的每次实际 HTTP 尝试在同一后端进程内至少间隔 5 秒，包括刷新、翻页、RSS 回退和允许的重定向。等待可取消，并受现有超时约束；队列和间隔时间仅存内存，不进入数据库、备份或同步，不跨进程或设备共享。Bangumi API 的应用标识现包含维护者公开署名 Rena、应用名和实际版本；公开主页确定并写入项目清单后也会附在标识中，不附用户邮箱或本机路径。

页面不再从 Google Fonts 加载字体，使用系统字体回退。元数据／图片及进入下载页都可能联网，本应用并非永久离线工具。

## 缓存、备份与供应商数据

元数据搜索中间结果的内存缓存为 10 分钟，远程图片内存缓存为 5 分钟；绑定后的元数据写入 SQLite，海报保存到本地磁盘，不能理解为内存 TTL 到期就会删除这些持久数据。下载列表结果另使用默认 30 秒的内存缓存。

本地数据库备份可能包含已保存的供应商元数据及凭据，海报增量备份默认开启；自动 DB 备份保留最近 10 份，不代表所有海报副本按同样方式清理。备份过程不把数据库上传给 AniList、Bangumi 或 TMDB。恢复后缺图补抓可能再次请求供应商，这是独立的恢复后行为。

授权本机外部客户端读取、备份和导出会扩大已保存元数据的可见范围，不能把“未随安装包提供数据”理解为运行中不存在数据转交。上述是代码行为说明，不是第三方对全部缓存／转交的授权；条款及尚未解决的限流、机器访问规则见 [第三方台账](THIRD-PARTY.md)。本次条款核对没有修改这些行为或删除任何已有记录。

后续限流修复为 TMDB、AniList API 增加共享的本进程冷却状态，仅保存供应商类型和下次允许请求的时间，不保存网址、Key、查询词或上游正文，不进入数据库、备份或同步。当前请求遇到 429 后不自动重试；冷却期内返回等待提示，到期后允许新的调用。两家供应商互不阻塞；该策略不覆盖图片 CDN、Bangumi 或下载站，不取消其他媒体库任务，也不是跨设备共享的全局配额保证。应用仍不内置 TMDB 默认 Key。

## 日志、备份与对外分享

排错材料可能包含路径、操作记录和异常信息。不要将整个数据目录、服务控制记录、完整备份或未审阅的截图提交到公开仓库。第三方数据／图片、API 和下载站的许可与商业使用条件见 [第三方台账](THIRD-PARTY.md)；功能内置不是合规放行结论。
